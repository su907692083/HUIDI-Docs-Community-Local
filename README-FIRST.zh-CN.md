**客户 / 商品 → 询盘 / 订单 → 产品目录 → 报价单 → PI → 销售合同 → 商业发票 / 装箱单 → 出运 / 复购**

## Windows 小白怎么打开

1. 解压整个 ZIP，不要只打开压缩包里的文件。
2. 双击 `START-HUIDI-LOCAL.cmd`。
3. 浏览器会自动打开 `http://127.0.0.1:8765/`。
4. 推荐使用最新版 **Microsoft Edge 或 Google Chrome**。

## 第一次怎么用

1. 先到 **客户中心** 保存客户资料。
2. 再到 **商品资料库** 保存商品。
3. 收到客户需求后，到 **询盘与订单** 新建一条业务，把客户和商品关联起来。
4. 客户要看产品，从业务或商品库制作 **产品目录**。
5. 客户问价，制作 **报价单**；确认后继续 **PI → 销售合同 → CI → 装箱单**。
6. 定期进入 **备份与迁移** 导出完整 JSON 备份。

## 可以放自己服务器吗？

**可以。**

个人可以部署在自己的服务器、NAS、VPS、私有云；公司可以部署到自己公司的服务器或内网供员工内部使用。

但如果你把 HUIDI 部署给其他客户使用并收钱，或做收费 SaaS / 托管 / OEM / 白标，就需要商业授权。

## 哪些可以断网

- 客户、商品、本机商品图片、询盘 / 订单、品牌、常用条款
- 单据编辑与本地草稿
- PDF / XLSX / CSV 导出
- 产品目录排版与本机图片
- 本地备份 / 恢复

## 哪些需要联网

- 你主动填写的网络图片链接
- 打开来源网页、产品视频网页
- 打开 Gmail / Outlook 等外部邮箱
- 云 AI、云同步、团队通知不包含在 Community Local

## 数据提醒

本地版的数据主要保存在当前浏览器。清理站点数据、重装浏览器、换电脑前请先导出备份。
