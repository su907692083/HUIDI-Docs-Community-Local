## Windows 小白怎么打开

1. 解压整个 ZIP，不要只打开压缩包里的文件。
2. 双击 `START-HUIDI-LOCAL.cmd`。
3. 浏览器会自动打开 `http://127.0.0.1:8765/（若端口已占用会自动切换到 8766–8775）`。
4. 推荐使用最新版 **Microsoft Edge 或 Google Chrome**。

## RC16.29 使用提示

- 在“商品”里上传的本机商品图片，现在进入 **产品目录** 后会直接复用，不需要再次上传。
- 商品的规格、MOQ、HS Code、报关、原产国、包装、重量、CBM、唛头等资料会继续作为目录商品信息来源。
- 从工作台点“做目录 / 产品目录”时，目录制作器会按商品 ID 读取当前最新商品主数据，而不是保留一份失去更新的副本。
- 产品目录页面不再重复显示两遍“目录制作流程 / 返回工作台”。
- RC16.28 的表格式工作台录入、RC16.27 的无旧 UI 闪现和飞书资料修复继续保留。

## 第一次怎么用

1. 首页会直接显示 3 个准备项：**公司 / 收款、第一个客户、第一个商品**；缺哪项点哪项，不需要先学菜单。
2. 收到客户需求后，点左侧或顶部的 **新询盘**，把客户和商品关联到同一条业务。
3. 客户问价，点 **做报价 / 单据**；确认后继续 **PI → 销售合同 → CI → 装箱单**。
4. 客户先要产品资料时，从商品库或 **产品目录** 直接选商品制作。
5. 资料多以后，可用左侧查找框按客户名、SKU、HS Code 或单号直接定位。
6. 定期点左侧 **备份** 导出完整 JSON；需要团队协作时，可另外配置飞书云文档协作同步，它不替代完整备份。

## 可以放自己服务器吗？

**可以。**

个人可以部署在自己的服务器、NAS、VPS、私有云；公司可以部署到自己公司的服务器或内网供员工内部使用。

但如果你把 HUIDI 部署给其他客户使用并收钱，或做收费 SaaS / 托管 / OEM / 白标，就需要商业授权。

## 哪些可以断网

- 客户、商品、本机商品图片、询盘 / 订单、品牌、常用条款
- 单据编辑与本地草稿
- PDF / XLSX / CSV 导出
- 产品目录排版与本机图片
- 本地备份 / 恢复

## 哪些需要联网

- 你主动填写的网络图片链接
- 打开来源网页、产品视频网页
- 打开 Gmail / Outlook 等外部邮箱
- 可选飞书云文档协作同步：需要联网，并使用你自己的飞书自建应用
- HUIDI 生产云、云 AI、私有团队通知不包含在 Community Local

## 数据提醒
