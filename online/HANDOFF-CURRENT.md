## 2. 产品定位

HUIDI Online 定位为：

**Foreign Trade Daily Workbench / 外贸人的每日专属工作台**。

核心日常链：

`今天 → 待跟进 → 客户回复 → 找客户 → 地图找客户 → 客户背调 → 联系人 → 产品资料 → AI 开发信 → 真实邮件 → 自动跟进 → 客户 / 询盘 → 商品 / 产品目录 → 报价 → PI → 合同 → CI / 装箱单 → 出运 → 下一步`

单据只是主链的一部分。

产品规则：
- 小白友好，普通页面只说业务语言。
- 一页式、表格、右侧详情、少跳页、少重复录入。
- 联网能力必须回到 Customer / Lead / Product / Deal / Mail / Document / Next Action。
- 未连接真实数据源时明确显示“未连接”，禁止演示数据冒充正式结果。
- Community Local 是本地 / 离线、文件和成熟单据能力补充，不限制 Online 的真实联网能力。
- 普通用户页面禁止出现代码仓库、开源项目、内部协议、数据库、租户、Schema、Prompt、Agent 等实现词。

## 7. 客户 / 询盘 / 单据

Online 已持续保存 Customer / Deal，同一业务对象保存客户、联系人、邮箱、国家、官网、询盘阶段、概率、金额、币种、需求、下一步、日期和单据关联。

### 联网业务参考

`OnlineIntelligenceRecord` 已持久化。

企业核验、贸易记录、市场动态、关税、汇率、船期 / 物流查询可以挂回当前 Lead / Deal。

业务详情已有“业务参考”：
- 显示已经查过哪些资料
- 根据当前业务 / 单据提示还建议补什么
- 不自动改写价格、产品参数、合同、装箱数据

制作报价 / PI / 合同 / CI / 装箱单时：
- 联网参考默认不会进入单据包
- 如果存在参考，页面先明确询问用户是否带入
- 用户确认后，服务器才把参考放入单据参考区
- 会保存“谁确认、何时确认、用于哪类单据”的 `DealReferenceApproval`
- 用户不确认时，不创建 approval，也不向正式单据包加入联网参考

## 8. 团队与多公司强隔离

控制面只保存：
- Organization / 公司工作区
- TeamMember / 成员
- TeamSession / 登录会话
- 角色与公司归属

角色：老板、管理员、业务员、只读成员。

业务数据采用物理公司边界：
- 公司 #1 继续使用历史 `DATABASE_URL`，历史业务数据不迁走。
- 公司 #2+ 使用独立业务数据库。
- SQLite 自动建立公司独立数据库文件。
- PostgreSQL / MySQL 等必须用 `HUIDI_TENANT_DATABASE_URL_TEMPLATE` 为每家公司提供独立数据库。
- 每个请求先确认成员属于哪家公司，再进入该公司的业务库。
- 相同 Lead ID / Deal ID 在不同公司也不会串数据。

已覆盖 Lead、Customer、Deal、Product Brain、Mail、Queue、自动跟进、联网资料、提醒、单据业务关联、审计和数据服务设置。

后台任务也按公司执行：
- 公司 #1 延续已有邮件 Worker
- 公司 #2+ 独立执行 Queue / Retry / 自动跟进 / Inbox Sync / Reply Sync
- 默认公司与单人模式也会自动执行外部提醒
- 外部提醒和自动备份不依赖必须开启团队模式

外部退信 / 退订回传在团队模式下必须同时提供回传密钥与公司编号，只写入目标公司业务库。

## 12. 公司业务备份 / 恢复

SQLite 部署已经形成公司业务备份：
- 每家公司单独备份
- SHA256
- SQLite integrity check
- 数据结构 fingerprint
- 备份说明文件
- 保留策略
- 下载
- 恢复前明确二次确认
- 恢复前自动再留一份 `before_restore` 安全备份
- 恢复后刷新数据库连接
- 安全密钥变化时停止恢复，避免加密邮箱 / 数据服务授权失效
- 公司 A 的备份不能恢复到公司 B
- 平台账号、公司列表、登录会话不进入公司业务备份
- 运行时备份目录已排除出源码跟踪

### 自动备份

默认：
- `HUIDI_AUTO_BACKUP=1`
- `HUIDI_AUTO_BACKUP_HOURS=24`
- `HUIDI_BACKUP_KEEP=30`

规则：
- 单人模式也运行
- 多公司逐公司判断
- 同一周期不重复创建
- 约每小时检查一次“是否到期”，默认每家公司约 24 小时保存一份已校验备份
- 自动备份失败进入 HUIDI 提醒和“上线检查”
- 历史“全部提醒”外部通知可以收到备份异常

非 SQLite 生产数据库不会假装由这套本地备份覆盖；必须使用数据库服务本身的自动备份 / PITR / 恢复能力。
