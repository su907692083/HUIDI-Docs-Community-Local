HUIDI Online · Windows 独立查看包

启动：双击“启动-HUIDI-Online.cmd”。
地址：http://127.0.0.1:8080/
停止：回到黑色启动窗口按 Ctrl+C。

本包会自动：
- 使用独立 Python 环境；
- 启动后打开默认浏览器；
- 为全部前端 CSS / JavaScript 生成内容哈希版本地址；
- 本地首页清理同一 HUIDI Online 地址遗留的旧脚本缓存，避免旧包脚本污染新包；
- 不再使用 Windows TIMEOUT 命令打开浏览器，避免不同系统语言下的语法错误。

如果上一版网页标签页已经处于“无响应”，可直接关闭那个旧标签页，再运行本包；不需要手工清理浏览器缓存。
