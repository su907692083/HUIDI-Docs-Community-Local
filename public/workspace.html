使用说明 / 浏览器兼容 / 离线边界

源码开放版默认走“轻量高级视觉”，没有 WebGL、粒子、重型 3D 引擎，对普通办公电脑要求很低。

推荐浏览器

  • 优先：最新版 Microsoft Edge / Google Chrome。
  • 大多数 Chromium 内核浏览器通常可运行，但下载、打印、剪贴板权限可能略有差异。
  • 如果 PDF / XLSX / CSV 下载异常，第一步先换 Edge 或 Chrome 复测。

可离线使用

  • 客户、商品、询盘/订单、品牌、模板、本地邮件草稿。
  • 单据编辑、PDF / XLSX / CSV、本地图片、备份/恢复。
  • 产品目录排版与本机图片。

需要联网的情况

  • 读取网络图片链接。
  • 打开外部邮箱、网页或来源链接。
  • 可选飞书云文档协作同步需要联网，并使用你自己的飞书自建应用。
  • HUIDI 生产云、云 AI 和私有团队通知不包含在 Community Local。

为什么不做重 3D？

本版本用 SVG 图标、渐变、阴影、微交互和轻量层次感提升质感，避免显卡占用、风扇噪音、老电脑卡顿和不同浏览器兼容风险。
