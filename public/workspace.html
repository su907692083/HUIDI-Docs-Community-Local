目录制作顺序

本地版推荐按这个顺序，最不容易重复劳动。

1
整理商品资料本机图片最稳定；网络图片链接需要联网。
2
选择商品进入目录从商品库直接带入，不再重新上传一份表格。
3
排版并导出 PDF目录编辑和本机图片可离线；外链图片需要联网读取。

单据中心

建议顺序：报价单 → PI → 销售合同 → 商业发票 / 装箱单。编辑器里会提供“继续下一张单据”的快捷入口。

备份与迁移

本地运行的代价是：你自己掌握数据，也需要自己负责备份。换电脑、清缓存、重装浏览器前必须先导出。

完整 JSON 备份

包含客户、商品（含本机图片 Data URL）、询盘、品牌、模板、邮件草稿和单据草稿。

重要提醒

浏览器清理站点数据可能会把本地资料一起删掉。不要把浏览器缓存当成永久数据库。

使用说明 / 浏览器兼容 / 离线边界

源码开放版默认走“轻量高级视觉”，没有 WebGL、粒子、重型 3D 引擎，对普通办公电脑要求很低。

推荐浏览器

  • 优先：最新版 Microsoft Edge / Google Chrome。
  • 大多数 Chromium 内核浏览器通常可运行，但下载、打印、剪贴板权限可能略有差异。
  • 如果 PDF / XLSX / CSV 下载异常，第一步先换 Edge 或 Chrome 复测。

可离线使用

  • 客户、商品、询盘/订单、品牌、模板、本地邮件草稿。
  • 单据编辑、PDF / XLSX / CSV、本地图片、备份/恢复。
  • 产品目录排版与本机图片。

需要联网的情况

  • 读取网络图片链接。
  • 打开外部邮箱、网页或来源链接。
  • 云 AI、云同步、团队通知不在本地源码开放版。

为什么不做重 3D？

本版本用 SVG 图标、渐变、阴影、微交互和轻量层次感提升质感，避免显卡占用、风扇噪音、老电脑卡顿和不同浏览器兼容风险。
