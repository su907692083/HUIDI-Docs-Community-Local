快速开始

第一次使用，只需完成 4 步

  1. 选择单据类型与语言报价单、PI、商业发票、装箱单、销售合同按实际业务使用。
  2. 填写或调用本机客户资料公司、商品、金额、银行与贸易条款由你自己核对和保存。
  3. 实时检查预览重点核对金额、日期、地址、付款信息、物流与签章。
  4. 保存并导出 PDF草稿保存在当前浏览器；重要数据建议同时导出本地备份。

基础单据信息

PDF 输出语言
用于控制 PDF 中的固定标题、字段名和表头语言。用户填写的商品名、备注和条款不会被强制翻译。
固定标题、字段名和表头支持 17 种单语 + 中英双语离线本地化；商品名、备注、条款等业务内容保持原文，除非你自行提供对应译文。

单据编号规则

推荐采用“前缀 + 时间代号 + 客户 / 国家代号 + 流水号”。出单日期变更时，未锁定的自动编号会同步更新；单据确认并发送后请锁定。

字段显示版本

默认版本按当前单据的标准字段输出；精细版本会展开当前单据可补充字段，勾选后同步到预览和 PDF。切换版本不会删除已填写内容。

默认版本：按当前单据标准字段输出，隐藏不适合该单据的扩展字段。

⚙ 选择显示在单据中的字段

Trade & Factory Control

外贸出单与工厂执行控制台 / TRADE & FACTORY CONTROL

用于管理业务场景、单据状态、修订版本、生产启动条件、样品 / 包装确认、检验标准和内部核算。内部成本不会进入客户 PDF、客户版 Excel 或 CSV。

自带 API 配置

仅支持 Google Gemini、阿里云百炼 / 千问、DeepSeek 与 OpenAI 四个预设通道。系统会锁定官方 API 地址，避免误填 URL 或使用未验证协议。

API Key 安全边界：HUIDI 不会将您的 API Key 写入云端、数据库、模板或浏览器本地存储。Key 只保留在当前页面内存中，用于您主动发起的测试或翻译请求；刷新、关闭页面或切换配置后需要重新输入。请求会经安全中转发送至您选择的服务商，请勿在公共电脑或不可信浏览器扩展环境使用。
配置说明：仅支持 Gemini、百炼 / 千问、DeepSeek 与 OpenAI。Gemini 使用原生 generateContent 协议；其余三项使用官方 OpenAI Chat Completions 兼容接口。API 地址由系统锁定，系统不提供自定义 URL、中转内网地址或未验证第三方接口。

买卖双方

PDF 固定标题的中英输出跟随页首“单据语言”。公司法定名称、联系人、电话、邮箱、税号与网站由你手动核对并保持原样。

买方、收货人、通知方与账单 / 送货地址（外贸高级字段）

买方 Buyer 是签约或付款主体；收货人 Consignee 是实际收货主体；通知方 Notify Party 是到港或交付通知对象。未填写时沿用买方资料，不会在 PDF 中重复显示。

一键粘贴识别买方信息

可直接粘贴客户邮件签名、名片文字、询盘内容或完整收货信息。系统会优先识别买方公司、联系人、电话、邮箱、网站、国家、ISO 国家代码、地址、税号及目的地；不必每行都写字段名，但填充后请人工核对。

核验入口仅帮助搜集公开信息，不构成真假客户或信用能力的结论；点击后搜索信息会由相应第三方平台接收。

商品明细

海关编码、单位和产品图片可按需显示在 PI 中。商品名称、规格和描述由你自行填写与核对；页首“单据语言”主要控制固定标题与表头输出。

翻译与 PDF 单语 / 双语输出统一跟随页首“单据语言”。仅翻译商品名称、规格与附加费用名称；型号、SKU、HS Code、单位、数量、单价、金额与品牌保持原样。

折扣（可选；未填写或为 0 时，不会显示在单据与 PDF 中）
金额大写（可选；适合大额 B2B、银行或企业审批场景）

只有在精细版本中勾选“显示金额大写”，并且存在有效金额或手动覆盖内容时，才会进入 PDF。

物流信息（可选）

适用于 FOB、CIF、CFR 等传统 B2B 场景，便于买方测算运费。

翻译与 PDF 单语 / 双语输出统一跟随页首“单据语言”。运输方式、包装说明与物流文字可翻译；箱数、重量、CBM 与唛头中的编号保持原样。

自定义物流字段（可选）适合承运人、提单号、柜号、封条号、ETA、包装尺寸等行业补充信息；未填写不会显示。

收款账户 / 付款信息

翻译与 PDF 单语 / 双语输出统一跟随页首“单据语言”。收款人、开户行、账号、SWIFT、支付链接与平台名称始终保持原样；仅处理地址或说明文字。

收款账户安全核对填写收款资料后，请确认收款人、账号和 SWIFT。账户变化时系统会提醒复核，但不会阻止导出。
一键粘贴识别收款信息

可粘贴银行账户、PayPal、Western Union 或阿里信保资料。建议按“字段名：内容”逐行粘贴，系统会按当前收款方式自动填充；请务必核对账户、收款人、SWIFT 与链接。

可选择预设渠道，也可选择“自定义收款渠道”填写其他银行、平台或付款链接。收款模板保存在当前浏览器；仅在至少填写一项收款资料时，预览与 PDF 才显示本区。

* 正式收款服务推荐与客服配置待接入。当前版本仅显示正式配置待接入提示。

交易条款

固定标题将跟随单据语言使用系统术语库；卖方公司、买方公司 / 收货人、付款、交期、物流与条款标题会与内容同步输出；常用付款、交期、质保与备注可从右侧内容库一键写入。

翻译与 PDF 单语 / 双语输出统一跟随页首“单据语言”。付款条款、交期、港口说明与备注可翻译；FOB、CIF、EXW、DDP 等 Incoterms® 缩写始终保持原样。
